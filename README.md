# EgeTracker

Оффлайн-приложение для подготовки к ЕГЭ и самообразования.
Предметы: математика (профиль), русский язык, информатика, английский язык, Linux.

## Возможности

- Трекер прогресса с круговыми диаграммами и прогресс-барами.
- Решение прототипов заданий из банка ФИПИ.
- Решение полных вариантов с переводом первичных баллов в 100-балльные.
- Работа над ошибками: видеоразбор + 15 аналогичных заданий.
- Заметки с минимальным форматированием (RTF).
- Маркер/ластик поверх задания (InkCanvas).
- Светлая/тёмная тема, свой фон.
- Все данные — локально, в JSON-файлах рядом с .exe.

```powershell
dotnet publish -c Release -r win-x64 --self-contained true `
  /p:PublishSingleFile=true `
  /p:IncludeNativeLibrariesForSelfExtract=true `
  /p:EnableCompressionInSingleFile=true
