🐧 Linux — Справочник команд

1. Навигация

КомандаОписание
pwdПоказать текущий каталог
ls -laСписок всех файлов с деталями
cd /pathПерейти в каталог
cd ..На уровень вверх
cd ~В домашний каталог

2. Работа с файлами

КомандаОписание
cp -r src dstКопировать рекурсивно
mv src dstПереместить / переименовать
rm -rf dirУдалить рекурсивно
touch fileСоздать пустой файл
mkdir -p a/b/cСоздать вложенные каталоги
cat fileВывести содержимое

3. Права доступа

КомандаОписание
chmod 755 filerwxr-xr-x
chmod 644 filerw-r--r--
chown user:group fileСменить владельца
umask 022Маска по умолчанию

4. Поиск

grep "pattern" file.txt            # поиск строк
grep -r "pattern" .                # рекурсивный поиск
find / -name "*.txt"               # поиск файлов
find / -size +10M                  # файлы > 10 МБ
which command                      # путь к команде

5. Процессы

КомандаОписание
ps auxВсе процессы
topМониторинг в реальном времени
htopУлучшенный top
kill -9 PIDУбить процесс
jobs / fg / bgУправление задачами

6. Сеть

КомандаОписание
ip aПоказать IP-адреса
ping hostПроверка доступности
curl urlHTTP-запрос
wget urlСкачать файл
ssh user@hostПодключиться по SSH

7. Архивация

tar -czf archive.tar.gz dir/       # сжать
tar -xzf archive.tar.gz            # распаковать
zip -r archive.zip dir/            # zip
unzip archive.zip                  # распаковать zip
💡 Совет: используй man command для справки по любой команде.
